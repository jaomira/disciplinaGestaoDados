1. Criar a empresa
Cada grupo deveria definir:
- Nome da empresa
- Segmento de atuação
- Missão
- Visão
- Valores
- Produtos/serviços
- Clientes
- Fornecedores e parceiros
- Organograma
- Principais processos
- Objetivos estratégicos


2. Criar um projeto de software
- A empresa deveria possuir um sistema/produto de software relacionado ao seu negócio.
- Os alunos deveriam levantar:
- Quais dados o sistema produz e utiliza;
- Quem utiliza esses dados;
- Onde os dados são armazenados;
- Dados sensíveis;
- Problemas relacionados aos dados;
- Riscos;
- Necessidades do negócio.
